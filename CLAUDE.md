# Фокус — правила для Claude Code

Приложение-блокировщик для Android (бывший MiniLauncher; пакет прежний `com.kolya.minilauncher`,
чтобы обновления приходили через Obtainium). target/compile SDK 37, minSdk 30.
Рабочий стол — стандартный от Google; «Фокус» лаунчером больше не является.

## Стек
- Java 17, Android SDK, без AndroidX. Единственная библиотека — zxing core (QR-код ключа).
- UI собирается кодом (без XML-разметки), стиль — в `Ui`. Картинки — векторные `res/drawable/ill_*.xml`.
- Настройки — SharedPreferences (`Prefs`).

## Как устроено
- `Guard.check()` — единственное место, где решается, можно ли открыть приложение
  (ночь, блок видео, обход фильтра, правила приложений, временный доступ по коду).
- `GuardService` (AccessibilityService) — видит открытое приложение, показывает `BlockActivity`,
  проверяет адресную строку браузеров, закрывает экраны настроек, где «Фокус» можно отключить/удалить.
- `FilterVpn` — локальный VPN только для DNS: видеодомены получают 0.0.0.0, серверы DoH закрыты.
- `Totp` — коды Google Authenticator, каждый код одноразовый.
- `InboxService` (NotificationListenerService) + `Inbox` + `InboxActivity` — «Сообщения»: общие входящие
  Telegram, WhatsApp, Viber и VK из их уведомлений (файл `inbox.json` только на телефоне). Ответ уходит
  через кнопку «Ответить» самого мессенджера (RemoteInput), «Фокус» сам ничего в сеть не шлёт.
  Отдельный значок на рабочем столе — `activity-alias` `.InboxLauncher`.
- `Net` — с разрешением WRITE_SECURE_SETTINGS (adb) сам включает защиту обратно и выключает «Частный DNS».

## Правила
- Любое ослабление ограничений — только через `requireCode()` (код владельца ключа). Ужесточение — без кода.
- Списки доменов и приложений — только в `Lists`.
- Наружу ничего не отправлять: сеть используется только для пересылки обычных DNS-запросов.
