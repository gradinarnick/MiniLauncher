# Фокус

Блокировщик для Android: закрывает всё видео (в любом браузере и приложении), ставит правила
на любые приложения, включает ночной режим и чёрно-белый экран. Ослабить что-либо можно
только одноразовым кодом из Google Authenticator владельца ключа.

## Что умеет
- **Видео:** YouTube, TikTok, VK Видео, Rutube, Netflix, Кинопоиск, Twitch, Дзен и др. закрыты
  во всех браузерах (фильтр сети + проверка адресной строки). Видеоприложения и плееры закрыты.
  Браузеры со встроенным VPN и VPN-приложения закрыты. Видео внутри Notion можно разрешить.
- **Правила для любого приложения:** пауза перед открытием, лимит минут в день, расписание, запрет.
- **Ночной режим** (по умолчанию 20:00–9:00): только звонки, будильник, Библия и разрешённое.
- **Чёрно-белый экран** всего телефона.
- **Временный доступ** по коду: всё / только видео / одно приложение на 15 мин – 2 часа.
- **Защита:** экраны настроек, где «Фокус» можно отключить или удалить, закрываются.

## Установка
Сборка и релиз — GitHub Actions при каждом push в main. Телефон получает обновления через Obtainium.

После установки на главном экране «Фокуса» 4 шага: ключ (делает владелец ключа), защита
в «Специальных возможностях», фильтр видео (VPN), защита от удаления.

Один раз через компьютер (необязательно, но делает защиту сильнее и включает ч/б экран):
```
adb shell pm grant com.kolya.minilauncher android.permission.WRITE_SECURE_SETTINGS
```
