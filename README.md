# Mini Launcher

Минималистичный текстовый лаунчер для Android 17 (работает на Android 11+).
Сделан по выводам исследования: обычное приложение с ролью домашнего экрана,
без интернета, без AccessibilityService, без сторонних библиотек.

## Что умеет

- **Главный экран:** часы и дата, до 8 избранных приложений текстом.
  Нажатие на часы открывает будильник, на дату открывает календарь.
- **Свайп вверх:** список всех приложений с мгновенным поиском.
  Enter открывает первое найденное. Можно включить автозапуск, когда найдено одно приложение.
- **Свайп вниз:** шторка уведомлений.
- **Долгое нажатие на приложение:** на главный экран / убрать, скрыть, переименовать,
  «О приложении», удалить. На главном экране можно ещё менять порядок.
- **Долгое нажатие на пустом месте:** настройки (фон из обоев или чёрный OLED,
  клавиатура, автозапуск, дата, скрытые приложения, обои, лаунчер по умолчанию).
- Скрытые приложения не видны в списке, но находятся поиском.
- Поддерживается рабочий профиль (помечается «·раб»).
- Никакой сети, телеметрии и рекламы. Разрешений всего два:
  шторка уведомлений и запрос на удаление приложения.

## Как получить APK

### Вариант 1. Android Studio (проще всего)
1. Установи Android Studio (https://developer.android.com/studio).
2. File → Open → выбери папку `MiniLauncher`. Подожди синхронизацию Gradle
   (Studio сама скачает Gradle 9.7.1 и SDK 37, если предложит, соглашайся).
3. Build → Build App Bundle(s) / APK(s) → **Build APK(s)**.
4. Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

### Вариант 2. Командная строка (если Android SDK уже установлен)
```
./gradlew assembleDebug
```

### Вариант 3. Без установки чего-либо: GitHub Actions
Загрузи папку в свой репозиторий на GitHub. Сборка запустится сама.
APK будет во вкладке **Actions → последний запуск → Artifacts → MiniLauncher-apk**.

## Установка на телефон
- Через USB: `adb install -r app-debug.apk` (рекомендуется, так меньше ограничений Android 15+).
- Или скопировать APK на телефон и открыть (разрешить установку из этого источника).
- После первого запуска лаунчер сам предложит стать домашним экраном.
  Вернуть стандартный: Настройки → Приложения → Приложения по умолчанию → Главный экран.

## Известные ограничения (из исследования)
- На Xiaomi/HyperOS жесты навигации со сторонним лаунчером могут переключиться на 3 кнопки;
  на OnePlus/Oppo анимация «домой» может подтормаживать. Это ограничение Android, не лаунчера.
- Private Space (Android 15+) пока не показывается: нужно отдельное разрешение и UI.
- Блокировка экрана двойным тапом не сделана намеренно: она требует AccessibilityService.
